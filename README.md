# chickenbot pages!
A place to keep the Privacy Policy and Terms of Use for the Chickenbot.


You can invite the bot to your discord server [Here](https://discord.com/oauth2/authorize?client_id=1346685695111991348)

The bot in it's current form requests Administrator permissions to the server. This will likely change in the future to be more granular, but that's what it is for now. If that's a worry, this probably isn't the bot for you.

You'll need to drag the bot's role above all others in the server settings roles page, for the nickname setting functionality to work. The bot can never change the server owner's nickname, this is something discord does not let any user or bot do.
