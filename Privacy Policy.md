Privacy Policy
What I collect: When you manually save a quote, or anything else, this bot stores the provided text, your Discord User ID, and the Server (Guild) ID. I do not collect passwords, emails, or store any messages that you haven't explicitly submitted to the bot. The bot does read incoming messages for some trigger phrases, but none of these get saved anywhere.
How it's stored: Data is saved in a database on a private server with restricted access. The database itself is not encrypted at rest, and as the bot developer, I have direct administrative access to it for maintenance. While access to the server is locked down, this is a hobby project and I cannot guarantee absolute security against breaches.
Sharing: I will never sell your data, use it for advertising, or post it publicly outside of the Discord servers where you use the bot.
Data Deletion: If you want your saved quotes or User ID removed from the live database and backups, contact me and I will delete them.
